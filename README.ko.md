# 산업단지 입지 및 입주기업

> ### **[▶ 지도 열기](https://wherewindstay.github.io/korea-industrial-complexes/)**
>
> *지도는 링크로 열어야 함. GitHub 는 README 안에서 대화형 화면을 실행하지 않음.*

전국 산업단지(국가·일반·도시첨단·농공)와 자유무역지역·외국인투자지역·연구개발특구·지식산업센터를 지정연도 또는 준공연도 순으로 지도에 쌓아 보는 자료. 단지를 누르면 하위지구, 분기별 가동률·입주업체·분양률·고용, 연간 생산, 입주업체 목록이 나옴.

| 구분 | 수 | 기준 |
|---|---|---|
| 산업단지 | 1,370곳 (국가 55 · 일반 774 · 도시첨단 55 · 농공 486) | 산업입지정보시스템 2026년 8월 말 |
| 자유무역지역 | 14곳 | 산업통상자원부 지정 고시 |

| 지식산업센터 | 1,553곳 | 팩토리온 2026년 9월 말 |

## 자료

- 단지 목록·지정일·준공인가일·조성상태·하위지구: 한국산업단지공단 산업입지정보시스템 「단지별현황 > 일반현황」
- 분기 통계(가동률·입주업체·분양률·고용·생산): 한국산업단지공단 「전국산업단지현황통계」(KOSIS), 2001년 1분기~2026년 2분기
- 단지 경계: 국토교통부 「산업단지 경계도면」(공공데이터포털 15152766)
- 입주업체: 팩토리온 「전국(개별,계획) 입주업체현황」·「산단공 관할단지내 입주업체리스트」(2026년 9월 말, 공공데이터포털 이용허락범위 제한 없음), (사)한국농공단지연합회 「전국농공단지현황」, 연구개발특구진흥재단 입주관리시스템 「입주기업현황」
- 업체 목록에는 회사명·생산품·종업원 수·기업형태만 실음. 대표자명·연락처는 싣지 않음
- 자유무역지역·외국인투자지역·연구개발특구: 국가법령정보센터 행정규칙(지정 고시), 관리기관 누리집. 지구마다 근거 링크를 지도 상세에 표시
- 배경지도: © OpenStreetMap 기여자(ODbL), 타일 OSM Deutschland

## 방법

- 국가산업단지 55곳은 단지마다 대조표를 만들어 통계·경계와 이음. 일반·도시첨단·농공은 단지명(유형 접미어·주석·시군 접두어를 걷은 것)과 유형·시도로 자동 대조
- 경계도면에 이름이 줄여 적힌 경우(「송도지식」 등)는 같은 유형·시도에서 한쪽 이름이 다른 쪽의 앞부분이고 후보가 하나일 때만 이음
- 준공연도는 상위단지의 준공인가일 기준. 준공인가일이 없는 조성중 단지는 지정연도부터 같은 유형 색으로 그리고 준공 집계에서는 뺌
- 지점 위치(자유무역지역·외국인투자지역·연구개발특구·지식산업센터)는 주소를 지도 검색으로 찾은 것만 찍음. 근사 위치는 쓰지 않음

## 한계

- 2013년 이전 통계표와 2014년 이후 파일통계표는 집계 기준이 달라 경계에서 값이 끊길 수 있음
- 일반·농공단지는 2008~2013년 업체·고용 표가 없음. 2013년 이전 생산은 넣지 않음
- 팩토리온이 여러 단지를 한 이름으로 묶은 경우(성서 1~4차, 구미 1단지와 2~4단지 등)는 어느 단지인지 가를 수 없어 입주업체를 붙이지 않음. 계획입지 공장의 86%를 단지에 붙임
- 외국인투자지역 개별형 공식 명단(2024-07)은 구하지 못해 2011년 명단과 일부 시·도 현황표로 채움
- 지식산업센터는 승인일·준공일 자료가 없어 연도와 상관없이 현재 위치로 보임. 위치를 찾은 곳은 1,553곳 중 1,087곳
- 최초 입주승인 연도 그래프는 지금 입주한 업체만 담아 과거 연도일수록 적게 잡힘
